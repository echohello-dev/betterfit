Containerless stat for a supporting row beneath a headline number.

```jsx
<div style={{ display: 'flex', gap: 20 }}>
  <OverviewStat icon="calendar" value="3" label="This week" />
  <OverviewStat icon="heartbeat" value="72%" label="Recovery" />
</div>
```

Use `StatTile` when the stats need their own cards.
