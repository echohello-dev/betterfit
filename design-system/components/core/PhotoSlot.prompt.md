Holds a photograph. Renders a labelled dashed slot until a real `src` exists — BetterFit ships no imagery.

```jsx
<PhotoSlot width={168} height={240} label="Lat pulldown" alt="Lat pulldown demonstration" />
<PhotoSlot src="/photos/lat-pulldown.jpg" alt="Lat pulldown demonstration" />
```

Never fill a photo position with stock imagery, an illustration, or a flat colour block — leave the slot visible so the missing asset stays obvious.
